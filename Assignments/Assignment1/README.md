REQUIREMENTS
Python 3.9+ with these packages installed:
    numpy, pandas, scipy, statsmodels, matplotlib

Install with:
    pip install numpy pandas scipy statsmodels matplotlib

HOW TO RUN
1. Keep Assignment1.py and all five CSV files (problem1.csv through problem5.csv)
   in the same folder.
2. Run:
    python Assignment1.py
3. The script prints every number referenced in the write-up (moments, quantiles,
   regression coefficients, AICc values, coverage percentages, etc.) to the
   console, in order by problem number.
4. Several plots will pop up in their own windows (scatter plots, the pairwise
   grid, ACF/PACF, the conditional mean band). The script pauses at each one -
   close the plot window and it will continue to the next section on its own.

OUTPUT
Every number in Assignment1_Answers.pdf comes directly from this script's printed output.
